Document Structure

<!DOCTYPE html>

This tells the browser that the page is written using modern HTML. It should be placed at the very beginning of the HTML file.

<html>

This is the main container of an HTML page. All the HTML content normally goes inside this tag.

<head>

This contains information about the webpage that the browser needs. Things like the title, CSS, and metadata are normally placed here.

<title>

This gives your webpage a title. You normally see this title in the browser tab.

<body>

This contains the content that visitors see on the webpage. Text, images, buttons, forms, and other visible content go here.

<meta>

This provides extra information about your webpage to the browser. It is commonly used for character encoding and responsive design.

<link>

This connects your HTML page with another resource. It is commonly used to connect an external CSS file.

<style>

This allows you to write CSS directly inside your HTML file. You can use it to control colors, fonts, spacing, and layout.

Headings and Text

<h1> - <h6>

These tags create headings. H1 is normally the most important heading, while H6 represents a lower-level heading.

<p>

This creates a paragraph of text. It is one of the most commonly used HTML tags.

<br>

This creates a line break. It moves the following content to a new line without creating a new paragraph.

<hr>

This creates a thematic break between content. Browsers usually display it as a horizontal line.

<strong>

This tells the browser that the text is important. It normally appears bold, but its main purpose is to show importance.

<em>

This gives text emphasis. Browsers normally display emphasized text in italic.

<b>

This makes text visually bold. It is mainly used when you want text to stand out without giving it special importance.

<i>

This represents text that is different from normal text. It is commonly displayed in italic.

<small>

This displays text as smaller side information. Copyright notes and fine print are common examples.

<mark>

This highlights text that you want the reader to notice. Browsers normally display it with a highlighted background.

<del>

This represents text that has been deleted. Browsers normally show a line through the deleted text.

<ins>

This represents text that has been added to a document. It can be useful when showing changes.

<s>

This shows text that is no longer correct or relevant. The browser normally puts a line through it.

<span>

This is a general inline container with no special meaning. It is often used to style a small part of text with CSS.

Links

<a>

This creates a clickable link. The href attribute tells the browser where the link should go.

Lists

<ul>

This creates an unordered list. The items normally appear with bullet points.

<ol>

This creates an ordered list. The items normally appear with numbers.

<li>

This represents one item inside a list. It is normally placed inside a UL or OL element.

<dl>

This creates a description list. It is useful for showing terms together with their explanations.

<dt>

This represents the term in a description list. Think of it as the word you want to explain.

<dd>

This contains the explanation of a term. It normally comes after a DT element.

Page Structure

<header>

This represents the introductory area of a page or section. It can contain a logo, heading, navigation, or introduction.

<nav>

This contains important navigation links. A website's main menu is a common example.

<main>

This contains the main content of the webpage. It should contain the information that is most important to the page.

<section>

This groups related content together. For example, About, Services, and Contact can each be separate sections.

<article>

This represents content that can stand on its own. Blog posts, news articles, and forum posts are common examples.

<aside>

This contains information related to the main content but not essential to it. Sidebars and related links often use it.

<footer>

This represents the bottom part of a page or section. Copyright information and extra links often go here.

<div>

This is a general-purpose container. It is commonly used to group content so that CSS or JavaScript can work with it.

Images and Media

<img>

This displays an image on your webpage. The SRC attribute tells the browser where the image is located, while ALT describes the image.

<figure>

This groups self-contained content such as an image or diagram. It can be combined with a caption.

<figcaption>

This provides a caption for content inside a figure. It helps explain what an image or diagram represents.

<audio>

This adds audio to a webpage. Users can normally play, pause, and control the sound.

<video>

This adds a video player to your webpage. It can be used for tutorials, movies, demonstrations, and other videos.

<source>

This provides a media file for audio, video, or picture elements. Multiple sources can be provided so the browser can choose one.

<track>

This adds timed text to audio or video. Subtitles and captions are common examples.

<picture>

This allows you to provide different images for different screen sizes or situations. It is useful for responsive images.

<iframe>

This displays another webpage or external content inside your webpage. Maps, videos, and documents can be embedded with it.

Tables

<table>

This creates a table with rows and columns. It should be used for displaying data, not for designing the webpage layout.

<tr>

This creates one row in a table. A row can contain header cells or normal data cells.

<th>

This creates a table header cell. It normally describes a column or row of information.

<td>

This creates a normal table data cell. It contains the actual information in the table.

<thead>

This groups the header rows of a table. Column headings are usually placed inside it.

<tbody>

This groups the main data rows of a table. Most of the table's content normally goes here.

<tfoot>

This groups the footer rows of a table. Totals and summaries are common examples.

<caption>

This gives a table a title or description. It helps users understand what the table is about.

Forms

<form>

This creates a form where users can enter information. Login, registration, search, and contact forms are common examples.

<input>

This creates an input field or control. Depending on its type, it can be a text field, checkbox, password field, date picker, and more.

<label>

This gives a form field a readable name. For example, it can tell the user that an input is asking for an email address.

<button>

This creates a clickable button. It can submit a form or perform an action using JavaScript.

<textarea>

This creates a multi-line text field. It is useful for comments, messages, descriptions, and feedback.

<select>

This creates a dropdown menu. Users can select one of the available options.

<option>

This represents one choice inside a dropdown menu. Users can select an option from the list.

<fieldset>

This groups related form fields together. For example, personal information fields can be placed inside one fieldset.

<legend>

This gives a fieldset a title. It tells users what the group of form controls is about.

<progress>

This shows the progress of a task. A file upload or download progress bar is a common example.

<meter>

This shows a value within a known range. Battery level, storage usage, or a score can be shown with it.

Interactive Elements

<details>

This creates information that users can open and close. It is very useful for FAQs and expandable content.

<summary>

This provides the clickable heading for a details element. Clicking it opens or closes the hidden information.

<dialog>

This represents a dialog box or popup. It can be used for messages, confirmations, or small forms.

JavaScript and Graphics

<script>

This adds JavaScript to a webpage. JavaScript can make the page interactive and change content dynamically.

<noscript>

This provides alternative content when JavaScript is disabled or unavailable. It gives users something useful instead of an empty area.

<canvas>

This creates a drawing area controlled by JavaScript. It can be used for games, charts, animations, and custom graphics.

<svg>

This is used for scalable vector graphics. It is useful for icons, logos, diagrams, and illustrations.

<template>

This stores HTML that is not displayed immediately. JavaScript can use it later as a template for creating content.

Old / Obsolete Tags

<center>

This was previously used to center content. It is obsolete now, so CSS should be used instead.

<font>

This was used to change the font, size, and color of text. Modern HTML uses CSS for these things.

<marquee>

This created scrolling text or content. It is obsolete and should not be used in modern websites.

<frameset>

This was used to divide a browser window into multiple frames. It is obsolete and should not be used in new websites.
