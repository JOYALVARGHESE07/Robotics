Basic HTML Tags

<html>

This is the main tag of an HTML page. All HTML content is written inside it.

<head>

This contains information about the webpage. The title and other settings are usually placed here.

<title>

This gives a name to the webpage. You can see it on the browser tab.

<body>

This contains everything that appears on the webpage. Text, images and buttons go inside it.

Text Tags

<h1> to <h6>

These tags create headings. H1 is the biggest and H6 is the smallest.

<p>

This is used to write a paragraph. It is one of the most common HTML tags.

<br>

This moves text to the next line. It creates a simple line break.

<hr>

This creates a horizontal line. It can be used to separate different parts of a page.

<b>

This makes text bold. It is useful when you want text to stand out.

<i>

This makes text italic. It can be used to give text a different style.

<strong>

This shows that some text is important. Browsers usually display it in bold.

<em>

This gives text emphasis. Browsers usually display it in italic.

Links and Images

<a>

This creates a link. Users can click it to go to another page or website.

<img>

This adds an image to a webpage. The image location is normally given using the src attribute.

Lists

<ul>

This creates a list with bullet points. It is called an unordered list.

<ol>

This creates a numbered list. It is called an ordered list.

<li>

This creates one item inside a list. It is used inside ul or ol.

Page Layout

<header>

This represents the top part of a webpage or section. It can contain a heading or logo.

<nav>

This contains navigation links. Website menus commonly use this tag.

<main>

This contains the main content of the webpage. It should contain the most important information.

<section>

This divides a webpage into different sections. Each section usually contains related content.

<footer>

This represents the bottom part of a webpage. Copyright and contact information can go here.

<div>

This is a general container. It is often used to group elements together.

Forms

<form>

This creates a form. It is used when users need to enter information.

<input>

This creates an input field. It can be used for names, emails, passwords, and other information.

<label>

This gives a name to an input field. It helps users understand what they should enter.

<button>

This creates a clickable button. It can be used to submit a form or perform an action.

<textarea>

This creates a large text box. It is useful for writing messages or comments.

Tables

<table>

This creates a table. It is used to display information in rows and columns.

<tr>

This creates one row in a table.

<th>

This creates a heading cell in a table. It usually contains the name of a column.

<td>

This creates a normal data cell in a table.

Other Useful Tags

<audio>

This adds audio to a webpage. Users can play and control the sound.

<video>

This adds a video to a webpage. Users can watch and control the video.

<iframe>

This displays another webpage or external content inside your page.

<script>

This is used to add JavaScript to a webpage. JavaScript makes webpages interactive.

<style>

This is used to add CSS to an HTML page. CSS controls how the webpage looks.
